思想专题 III

现代性与技术

技术时代，我们如何理解人的尺度？

专题总纲

现代技术的概念

不从“人对机器”的外在对立出发，也不把黑格尔文本直接当作现代技术史的预言。本专题以目的、中介、客观化和客观精神作为概念资源，重构现代技术怎样把人的目的固定在工具、机器、制度与信息结构之中，并由此追问自由在技术世界中的现实条件。

逻辑原则 “思维与存在的同一”在这里不是一条可以直接套用到技术史的公式。本专题借助黑格尔关于目的、中介与客观性的结构，提出一个现代解释命题：现代技术可以被考察为人的目的与能力取得客观持存的一组中介体系；这一命题属于本专题的哲学重构，而不是黑格尔对现代技术的直接定义。

概念道路 自由意志 → 目的 → 手段 → 工具 → 劳动 → 机器 → 分工 → 技术体系 → 市民社会 → 数量化 → 数据 → 算法 → 人工智能 → 判断 → 责任 → 承认 → 权利与制度 → 治理 → 具体自由 → 人的尺度。

阅读说明 本专题以黑格尔关于自由意志、目的论与客观精神的概念运动为直接文本基础；从数量化、数据、算法到人工智能的部分属于沿此逻辑所作的现代技术推演，不把这些对象倒置为黑格尔本人的历史论述。
