现代性与技术

技术时代，我们如何理解人的尺度？

专题总纲

现代技术的概念

不从“人对机器”的外在对立出发，也不把哲学原则套在技术之上；从现代技术的概念自身出发，追踪自由意志如何通过目的、中介与客观化成为技术世界。

逻辑原则 “思维与存在的同一”不是外在方法，而是事物本身的逻辑结构。现代技术是自由意志取得客观现实的中介体系；它的矛盾必须由概念自身展开。

概念道路 自由意志 → 目的 → 手段 → 工具 → 劳动 → 机器 → 分工 → 技术体系 → 市民社会 → 数量化 → 数据 → 算法 → 人工智能 → 判断 → 责任 → 承认 → 权利与制度 → 具体自由 → 人的尺度。
