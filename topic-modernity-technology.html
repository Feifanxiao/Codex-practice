思想专题 III

现代性与技术

技术时代，我们如何理解人的尺度？

专题总纲

思维与存在的同一

不从“人对机器”的外在对立出发，而追问思维如何客观化为技术世界，又如何在自己的客观世界中重新认识自由。

最高原则 思维不是站在存在之外的主观工具，存在也不是永远与思维隔绝的陌生物。技术是目的、手段、劳动与制度不断客观化的现代形态。专题的任务，是让这一客观化自身的矛盾把我们带回人的尺度。

概念道路 思维与存在 → 目的 → 手段 → 工具 → 劳动 → 机器 → 技术体系 → 抽象化 → 数据与算法 → 人工智能 → 主体性 → 承认 → 制度 → 具体自由 → 人的尺度。
